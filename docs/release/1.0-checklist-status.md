# 1.0.0 release checklist: status (#114)

**Status as of 2026-11-13**, checked against `integration/1.0-wave1` (main plus all wave 1 and 2 work) and against the
issue list on GitHub (read only). This file lets the maintainer tick the boxes of
[issue #114](https://github.com/TheEightBot/KumikoUI/issues/114); nothing on GitHub was edited.

Legend: `[x]` done, `[~]` partly, `[ ]` not done. "Done on the integration branch" means the work is committed on
`integration/1.0-wave1` but the GitHub issue is still open because that branch is not merged to `main`; close the issue
when it is. Issue states are as of this check. CI has not run on the integration branch (all verification was local), so
merging it to `main` and getting the required checks green is the first step below.

## Bottom line

Everything in the checklist is done or drafted except these, in the order they have to happen:

1. **Decide** the open questions in the next section (Uno GA or preview first: it changes the version scheme, the README
   and the NuGet README).
2. **Merge** `integration/1.0-wave1` (and the docs from this pass) to `main`; get `Build & Test`, the MAUI and Uno build
   jobs, snippets, identifiers and CodeQL green. Windows heads (MAUI `net10.0-windows*`, Uno desktop and WinAppSDK) have only
   ever been compiled in CI, never on this Mac, so this is the first time the integrated code builds for them.
3. **Open issues** for the verification follow-ups (Uno F1 to F10, MAUI follow-ups 1 to 5, API review F2 to F4).
4. **Cut the release commit**: `eng/update-public-api.sh`, move `Unshipped` to `Shipped` (api-review-1.0.md, "Steps at the
   1.0 tag"), cut the CHANGELOG `1.0.0` section from `docs/release/1.0.0-release-notes.md`, update stale statements
   (below).
5. **Rehearse** the publish workflow with dry run on, then tag `v1.0.0` (or the preview tag, see D-V) from `main`, approve
   the `nuget-publish` environment.
6. **After the tag**: enable `PackageValidationBaselineVersion`, make the `Shipped` files live in CONTRIBUTING, post the
   announcement.
